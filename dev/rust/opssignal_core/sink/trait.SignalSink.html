Expand description

A sink is a write-only side effect of the pipeline — not a queryable API the SDK exposes. Querying, dashboards, and aggregation are explicitly out of scope here; that’s the hosted control plane’s job, reading from the same store OSS users already populate.

Each signal is written twice: record before delivery starts, with status pending, and complete once the outcome is known. A signal whose process exits mid-delivery therefore stays visible as pending instead of vanishing.
