Source

pub fn discover() -> Result<Option<Vec<Self>>, SignalError>

$SIGNAL_CONFIG if set, else ./signal.yaml if it exists. A local $SIGNAL_CONFIG path that is not a file is an error rather than a silent fall back to defaults.

Source

pub fn join(&self, reference: &str) -> Result<Self, SignalError>

Resolves an extends entry of this file. A URL or an absolute path is taken as is; anything else is relative to this file’s own location, in the same bucket, container or directory.

A remote file may only extend other remote files: a config served over the network must not be able to read local paths.

Source

pub fn check_supported(&self) -> Result<(), SignalError>

Whether this build can read the source at all, either natively or through a registered ExternalFetcher. A missing one is an install problem, not an outage, so it fails loudly instead of falling back.
