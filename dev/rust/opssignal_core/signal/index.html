Signal
The generic signal model. id and timestamp are always stamped by the core (never trusted from the caller) so every downstream component — sink, dedup, retry tracking — has a stable identity and ordering guarantee regardless of which language binding produced it.
SignalInput
Builder input — what callers actually construct. Notably missing id and timestamp: those are not caller-settable. Every field may be left out of JSON input; validate reports the ones a signal needs.

Action
What a signal does to the alert its dedup_key names. trigger raises (or repeats) it; acknowledge and resolve act on an alert already raised with the same key, on the providers that have it. Added in v1.0.0-beta.3.
Severity
Severity is a closed enum, not a free string, so the routing engine can match on it exhaustively instead of doing string comparison.
